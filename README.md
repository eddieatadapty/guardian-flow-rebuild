# The Guardian Growth Audit

**Live → https://eddieatadapty.github.io/guardian-flow-rebuild/**

Five ideas to turn more The Guardian users into subscribers, each built into a clickable version of The Guardian's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask for support once, at the end of onboarding | +10–20% CR to purchase |
| 02 | Ask what they want to follow, before the feed | +10–20% CR to purchase |
| 03 | Make the annual saving impossible to miss | +5–15% CR to purchase, ARPU +10–15% |
| 04 | Show My Guardian before asking for an account | +5–10% CR to purchase, ARPU up to +17% |
| 05 | Catch the people who close the paywall | +10–15% ARPU |

Every price, rating and feature comes from The Guardian's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for The Guardian. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
